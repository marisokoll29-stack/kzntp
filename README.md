# KAZANTIP one-page + admin

Запуск без npm-зависимостей:

```bash
cp .env.example .env
# отредактируйте .env
node server.js
```

Сайт: http://localhost:3000/
Админка: http://localhost:3000/admin/

Через админку меняются:
- основные тексты сайта;
- существующие кнопки и их ссылки;
- Telegram-ссылка;
- валюта, наценка, минимальная сумма;
- категории калькулятора: добавление, удаление, цена, порядок, включение/выключение.

Настройки хранятся в `data/settings.json` и сохраняются атомарно.
